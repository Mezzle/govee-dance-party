1. Install the ESP32 image

One image runs standalone with the board’s button, or acts as a Bluetooth bridge for your Flipper Zero.

Browser flashing needs Web Serial. Try desktop Chrome or Edge, or download the image below and use esptool.

Open this page over HTTPS to enable browser flashing.

Use a USB data cable and close other serial apps. Installation replaces the board’s current firmware; erasing also clears saved census logs. If connection fails, hold BOOT while connecting, then release it. The Flipper Wi-Fi Devboard (ESP32-S2) has no Bluetooth and is unsupported.

Download merged image

Manual flashing: write the merged image at 0x0 with esptool. Generic boards may need UART pins adjusted in a source build.

2. Add the Flipper app

Choose the app matching your Flipper firmware, then copy the .fap file to SD Card/apps/Bluetooth/ using qFlipper’s file manager. Open it from Apps → Bluetooth.

Get qFlipper · Open Flipper Lab

Wire the ESP32 to the GPIO header and select Settings → Radio → ESP32 bridge. Flipper TX (pin 13) goes to board RX; Flipper RX (pin 14) goes to board TX. Connect 5V (pin 1) and GND (pin 8, 11 or 18).

Stock Flipper Bluetooth cannot control lights directly. See the board wiring guide for details. If an app reports an API mismatch, use a compatible firmware release or rebuild against your SDK.
